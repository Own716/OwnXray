# OwnXray for Android

<p align="center">
  <strong>OwnXray - Modern Universal Proxy Toolchain with Native Xray Core for Android</strong>
</p>

OwnXray 是一款全新自主研发、搭载官方原生 **Xray-core** 核心引擎的现代化 Android 代理客户端，采用纯正 Material 3 设计语言与高帧率原生交互体验。

### 特性亮点
- ⚡ **原生 Xray 核心**：深度支持 **VLESS**（Vision 流控 / REALITY）、**XHTTP** 传输协议、**VMess**、Trojan、Shadowsocks、gRPC、WebSocket、mKCP、TCP 等官方全套协议栈；
- 🎨 **全新自主研发界面**：专为原生 Android 打造的 Material 3 设计美学、高刷动态动效、卡片式测速与节点管理；
- 👑 **全新品牌视觉**：全新设计的应用图标与状态栏控制中心快捷开关（Quick Settings Tile）；
- 🛡️ **TUN 虚拟网卡与高精度分流**：支持高精度规则分流、本地 DNS 智能解析与分应用代理；
- 📊 **原生仪表盘与流量监控**：内置本地核心控制 API、多维连接监控与实时速率流式统计；
- 🚀 **自动化 CI/CD 构建**：支持 GitHub Actions 全自动化多架构 APK 打包与持续发布。
