# OwnXray for Android

<p align="center">
  <strong>OwnXray - Modern Universal Proxy Toolchain with Native Xray Core for Android</strong>
</p>

OwnXray 是一款搭载官方原生 **Xray-core** 引擎、拥有原生 Android Material 3 设计美学的现代化代理客户端。

### 特性亮点
- ⚡ **原生 Xray 核心**：深度支持 **VLESS**（Vision 流控 / REALITY）、**XHTTP** 传输协议、**VMess**、Trojan、Shadowsocks、gRPC、WebSocket、mKCP、TCP 等官方全套协议栈；
- 🎨 **Material 3 原生界面**：顺滑高帧、单手操作逻辑、卡片式测速与节点管理；
- 🛡️ **TUN 虚拟网卡与高精度分流**：支持高精度规则分流、本地 DNS 智能解析与分应用代理；
- 🚀 **自动化 CI/CD 构建**：支持 GitHub Actions 全自动化多架构 APK 打包。
